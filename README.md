# Hero's are delicious - 2D Physics Slime
**Project for Gi 204 Physics For Game**

---

# Project Description
A physics-focused 2D game where players control a slime character to navigate through levels.
* **Technical Highlights:** Implemented **Projectile Physics** as the core movement and interaction mechanic.

# Team Roles
* **Brocoliii:** Lead Programmer - Responsible for physics implementation and all core game logic.
* **YodkhwanA:** Level Decorator & Visual Designer - Responsible for environment aesthetics, scene organization, and visual polish.
